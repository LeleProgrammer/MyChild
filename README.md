# MyChild

**把十八年，慢慢写成一封家书。**

一款完全离线的中文文字成长模拟。玩家扮演家长，陪孩子从备孕走到十八岁，经历教育、家庭、经济、兴趣与关系的选择。采用温和写实的纸质档案风格，提供浅色、深色和跟随系统三种主题模式。

## 立即开始

1. 完整解压 `MyChild-v1.0.0.zip`。
2. 进入 `MyChild` 文件夹，双击 `index.html`。
3. 选择“开始一段十八年”，输入称呼；种子可以留空。

**不需要服务器、Node.js、npm、安装或构建。** 不要直接在压缩包预览器里打开 HTML，也不要只复制 `index.html`；其余脚本和样式应保持相对位置不变。

支持具备 ES2020 与 SVG 能力的现代桌面、平板和手机浏览器。手机文件管理器可能使用功能受限的内嵌预览器，遇到这种情况请改用真正的浏览器，或部署为静态网站。无网络也能完成全部游戏流程。

## 内容规模

| 内容 | 数量 / 说明 |
| --- | --- |
| 成长阶段 | 12，从备孕到高考结束 |
| 常规决策 | 48 |
| 职教变体决策 | 12，替换最后三个阶段的常规决策 |
| 随机事件 | 24，每阶段最多两个 |
| 内容选项 | 307，包含事件应对与职教变体 |
| 原创插画 | 12 幅内联 SVG |
| 主结局 | 11 类，职教类内含三种去向与结果分层 |
| 叠加结局 | 2 类：普通而完整的人生 / 家庭资源透支 |
| 成就 | 14，跨局保留 |

单局经历的是其中一条路线，不会同时经历所有 60 个决策。职教线三个阶段各有四个决策，并覆盖对口升学、技能就业、高职学习及未来专升本规划。

## 怎样操作

- 点击一个选项，再点底部“确认选择”；确认前可以改选。
- 数字键 `1`～`4` 选择，`Enter` 确认；后果页和阶段介绍页可用 `Enter` 继续。
- `Tab` 在控件间移动，`Esc` 关闭对话框；对话框支持焦点循环。
- 正在编辑输入框或选择科目时，不会触发全局数字键快捷操作。
- 小屏上点击顶部“家庭档案”即可展开状态。页面主内容使用外层滚动，没有嵌套的决策区滚动条。
- 右上角“主题”依次切换跟随系统、浅色、深色。
- 高一在表单中选择物理或历史，再选四门中的两门，最后确认。
- 高二可保持原组合，也可提交唯一一次转科申请，只能更换一门。

## 这款游戏如何看待成长

经济、精力和家庭关系都是抽象的 0～100 指标，不等于现实资产、时薪或医学指标。资源归零不会导致早期游戏结束，低资源时仍有免费的陪伴、调整计划和求助路径。

每阶段开始补充经济余裕和精力，孩子的学科能力也会因校内学习而增长。越接近高能力段，继续提升的增量越小；不再学习的科目会缓慢衰减。后果页展示的是经过成长折减和上下限处理后的实际变化。

亲子、压力与自主冲突在游玩中只显示文字档位，不显示具体数字。**结局复盘会揭开这些数字**，包括每一次选择的实际变化。心理状态会影响考试，过高压力也可能引发额外失常。低心理状态的故事会延续到阶段结算，最终可能暂停考试，避免把健康简单等同于分数。

本游戏不提供“每道题的正确答案”。路线、资源、关系和身体状态需要一起考虑。艺术、体育与竞赛不是绕过文化学习的自动录取按钮。

## 考试与路线

采用 **3+1+2、满分 750** 的综合模拟结构：语数外各 150，首选物理或历史 100，再选两门各 100，后两科按模拟位次进行等级赋分。

参考线采用偏中上竞争强度的游戏档位，并淡化地区概念：物理类本科 430、特控 520、名校 620、顶尖 660；历史类整体高 10 分。**这些数值不是剔除某些省份后计算出的真实统计平均值，也不对应任何具体省份、年份或录取承诺。** 游戏中的中考和特殊路线资格同样采用综合模拟参数，不代替真实政策查询。

中考模拟满分 750：重点高中参考线 590，普通高中参考线 440，以下进入完整职教分支。职教线最后采用独立的文化与技能综合考核，不伪装成普通高考；“专升本”只作为成年后的规划，尚未发生，不保证录取。

详细公式和结局条件见 [docs/MODEL.md](docs/MODEL.md)，包含机制剧透。

## 存档与迁移

- 每次选择确认、阶段推进和考试结算后自动保存。
- 首页“继续游戏”读取自动存档；右上角“存档”提供三个手动存档位和 JSON 导入／导出。
- 导出包含当前状态、随机数推进位置、人生记录及成就／结局图鉴。导入时图鉴与本地记录合并，不回滚已解锁内容。
- 载入发生在后果页时，不会重复收取代价，也不会重新抽取事件。
- 相同种子配合同一套选择，可以复现同一局。结局页可以使用原始种子重新开始。
- “导出人生回顾”生成独立 HTML 文件，内含完整时间线、成绩和矢量图表，可以离线打开或使用浏览器打印成 PDF。
- 损坏、超大或不兼容的 JSON 会被拒绝，当前局不会被替换。
- 浏览器存储不可用时，会在页面提示；游戏仍能运行，并可用 JSON 导出保留进度。

浏览器的本地存储按来源隔离。移动文件夹、换浏览器、无痕模式或清除站点数据，都可能使原本的自动存档不可见。重要进度请导出 JSON。用户称呼和进度仅存于本地，项目没有网络请求与数据上传。

## GitHub Pages 部署

1. 建立仓库，上传 `MyChild` 文件夹里面的项目文件，确保 `index.html` 在发布目录根部。
2. 在仓库的 Settings → Pages 选择从分支发布，选对应分支和根目录。
3. 等待 GitHub 完成发布即可访问。

运行时没有绝对资源路径，不要求自定义域名，可放在仓库子路径下。不要把整个 ZIP 当成网页入口上传。README、LICENSE 和 docs 可以一起保留。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面入口与脚本加载顺序 |
| `style.css` | 响应式、主题、动效、打印样式 |
| `data.js` | 全部剧情、选项、事件、结局、成就、UI 文案与平衡参数 |
| `art.js` | 十二幅原创内联 SVG |
| `game.js` | 单状态机、数值、随机、结算、存档与渲染 |
| `docs/MODEL.md` | 公式、分支条件与开发说明 |
| `docs/TEST_REPORT.md` | 交付检查范围与限制 |
| `tests/smoke.cjs` | 可选的无依赖开发检查，不参与运行 |
| `LICENSE` / `NOTICE.txt` | GPL-3.0-only 协议及作品说明 |

所有脚本均为普通 script，没有 ES Module、外部字体、图片请求、CDN、框架或构建依赖。数据不通过 fetch 或 XHR 读取。图表使用手绘 SVG，缩放和高像素密度屏幕上保持清晰，不需要 Canvas 的像素比补偿。

开发者可以在已安装 Node.js 的环境中执行：

```sh
node tests/smoke.cjs
```

这只是开发检查，玩家不需要 Node.js。
