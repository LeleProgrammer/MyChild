# MyChild 模拟模型与开发说明

本文件包含数值、结局及隐藏指标剧透。所有制度相关数值都是游戏参数。

## 状态与生命周期

`window.GAME_DATA` 包含全部数据；`window.Game` 暴露引擎接口。浏览器按 `data.js → art.js → game.js` 加载，均为普通脚本。

游戏使用一个 `state` 对象。游戏视图通过 `render()` 统一输出，阶段内流程为：

`intro → decisions → feedback → … → events → feedback → summary → 下一阶段`

最后一个阶段进入结果页。每次确认先结算一次并记录日志，再将阶段设置为反馈页；连续点击无法再次结算。

每阶段开头资源补充 money +25、energy +20，同样遵守 0～100 上限。包含第一个阶段，因此第一个介绍页显示经济 85、精力 95；初始对比图仍以原始 60、75 为起点。

所有数值变化通过 `applyEffects()`。真实变化可能受上下限和学科成长递减影响，时间线记录真实差值。

## 学业增长

正学业增量按能力所在区间逐单位累积，倍率如下：

| 当前能力 | 正增量倍率 |
| --- | --- |
| 低于 70 | 1.00 |
| 70～85 | 0.48 |
| 85～95 | 0.24 |
| 95 及以上 | 0.10 |

结果保留一位小数。负增量直接扣除。此规则让反复增加相同课程不至于过早把所有学科堆到满值。界面选项不承诺固定到分的结果；反馈页显示实际增量。

小学低段开始，每阶段结束结算校内学习：激活学科在自律低于 25 时不增长，25～64 增长基础 2，65 以上增长基础 3；仍经过能力递减。心理低于 25 时暂停校内正增长。未激活科目衰减 1。

小学阶段激活语数外；初中激活九门；普高激活语数外与三门选考；职教激活语数外。兴趣特长不套用学科成长递减。

## 隐藏指标

| 指标 | 文字档位 |
| --- | --- |
| 亲子关系 | 冰点 <20；疏远 <40；正常 ≤70；亲密 >70 |
| 压力 | 轻松 <30；正常 <60；紧张 ≤85；窒息 >85 |
| 自主与冲突 | 乖巧 <25；有主见 <50；顶撞 ≤75；对抗 >75 |

进行中不显示数字变化、数值轴或精确提示；完成后在图表、快照与时间线中揭示。此为用户确认的“结局揭示”模式。JSON 存档和源代码自然包含完整状态，不是防玩家查看的加密系统。

## 普通高考

理科类为数学、物理、化学、生物学，其他学科按文科权重。

```
理科基础得分率 = 0.76×科目能力/100 + 0.17×智力/100 + 0.07×自律/100
文科基础得分率 = 0.76×科目能力/100 + 0.08×智力/100 + 0.16×自律/100
心理扣减 = max(0, 55-心理健康) × 0.0032
压力扣减 = max(0, 压力-55) × 0.0020
最终得分率 = clamp(基础率-心理扣减-压力扣减+均匀扰动[-0.06,+0.06], 0.05, 1)
```

语数外乘 150，首选乘 100，均四舍五入计原始分。再选科的原始分也展示，但最后总分采用等级赋分。

再选模拟位次比例 `p = 1 - 得分率^1.05`，0 为最好，1 为最后。得分率由该科能力主导，同时计入状态和固定种子的考场波动。按下表分等，等级内线性映射后四舍五入：

| p 区间 | 等级 | 等内映射 |
| --- | --- | --- |
| [0, 0.15) | A | 100 → 86 |
| [0.15, 0.50) | B | 85 → 71 |
| [0.50, 0.85) | C | 70 → 56 |
| [0.85, 0.98) | D | 55 → 41 |
| [0.98, 1] | E | 40 → 30 |

六科合计最高 750。压力 >85 时，总分额外乘以由种子产生的 0.90～0.95 系数后取整。成绩表保留折减前各科分数，并明确展示额外失分，因此各科之和减去额外失分才等于最终总分。

心理 <20 时跳过评分，进入暂停考试主结局。此判定在十二阶段结束时执行，避免提前截断低状态家庭的恢复机会。

## 中考与职教

中考简化为语文 150、数学 150、外语 150、物理 120、历史 100、体能 80，共 750。文化科采用同一能力与状态得分率，体能由体质主导加波动。该结构用于游戏分流，不照搬某地考试科目与满分。

重点线 590，普高线 440。低于普高线进入职教三个完整变体阶段。

职教综合考核由语数外各 150（共 450）和技能综合 300 构成。技能基础 = 三项兴趣中的最高值×0.7 + 自律×0.3，加入固定种子的小幅考场波动后计分。独立标明为职教模拟考核。

- 对口升学：综合 ≥450 为模拟达标，否则展示较低层次或补基础后再争取。
- 技能就业：技能基础 ≥55 且自律 ≥40 为模拟岗位达标，否则先过渡与巩固。
- 高职起步：明确后续专升本只是规划，不能在十八岁时宣布已经取得本科录取。

## 高二转科

只可替换一个位置：物理与历史互换，或用未选的另一门再选替换原再选之一。组合中不会出现重复科目。新转入科目 -25，精力 -20，心理 -10，自律 +3；这次特殊转换依用户确认允许超过常规单项 20 的能力扣减。

确认后标记 `subject_transferred`。决策反馈页无法再次确认。其他阶段没有修改组合的入口。

## 特殊路线资格

选择路线意味着愿意投入，不代表自动录取。

- 艺术：高二选择艺术，最终音乐 ≥80，文化总分 ≥300。
- 体育：高二选择体育，最终体育 ≥80、体质 ≥60，文化总分 ≥300。
- 竞赛：高二结束先检查编程 ≥75、智力 ≥80、自律 ≥50、心理 ≥30，获得阶段审核通过标记；最终仍需编程 ≥75、智力 ≥80、文化总分达到本局特控参考线。

竞赛录取采用虚构的拔尖培养项目，不把信息学竞赛、强基和保送三种真实制度混为自动录取机制。阶段审核失败会明确告知，最终按普通高考档位结算。

## 结局优先级

1. 心理 <20：暂停考试。
2. 亲子 <20 且自主冲突 >75：亲子疏离。
3. 职教线：展示实际去向及其达标情况。
4. 艺术资格。
5. 体育资格。
6. 竞赛资格。
7. 顶尖参考线。
8. 名校参考线。
9. 特控参考线。
10. 本科参考线。
11. 其余：专科等后续路线。

并列叠加层：

- 非职教、分数 ≥480、亲子 >70、心理 >70、压力 <50，追加“普通而完整的人生”。
- 经济 <10 且分数低于本局特控参考线，或未考试，追加资源透支叙述。经济抽象值不直接等价于实际债务。

不使用 `eval` 或执行数据中的 `condition` 文本。条件文字供编辑阅读，程序按显式优先级判定。修改条件时需同步修改引擎的相应判定及测试。

## 事件、存档与安全

Mulberry32 风格 PRNG 保留原始 seed 和当前 rng。事件池的候选队列与已抽出的事件 id 保存进存档；同种子同选择可复现，读档不重新抽取。

阶段最多两个事件。低家庭关系优先加入冷战，低精力优先加入疲惫；备孕选择过二胎规划后，特定成长阶段可触发二胎事件。每个事件至少有一条主动应对路线。

主要 localStorage key：

- `raise_a_child_save_v1`：自动存档。
- `raise_a_child_achv_v1`：成就。
- `mychild_slots_v1`：三个手动档。
- `mychild_endings_v1`：结局图鉴。
- `mychild_theme_v1`：主题偏好。

所有存储操作用 try/catch 包裹。导入上限 2 MiB，验证版本、阶段、数值范围、组合、队列、日志、快照与结局等结构；不执行导入内容。自定义称呼和记录先 HTML 转义后渲染。图鉴导入采用已知 id 合并，不回滚已有记录。

## 开发接口

`Game.getState()` / `getSave()` 返回副本；可用 `start()`、`choose()`、`advance()` 进行确定性无 DOM 测试。`Game.assign()` 验证赋分边界；`Game.validate()` 验证存档。普通玩家不需使用控制台。

开发检查在 `tests/smoke.cjs`，仅使用 Node 内置模块。不要将测试生成的 QA 夹具或个人存档放进公开仓库。
