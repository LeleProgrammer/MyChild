# MyChild 1.0.0 交付检查

检查日期：2026-10-23。

## 自动检查

`node tests/smoke.cjs` 使用 Node.js 24 的内置 vm 与断言模块，不依赖 npm 包。最终执行结果全部通过。

- 12 阶段、48 常规决策、12 职教变体决策、24 事件、14 成就。
- 307 个选项均有反馈，数据影响均同时包含收益与代价。
- 常规单项增减不超过 20；一次转科的额外科目 -25 按单独规则处理。
- 高消费选项的经济门槛与费用匹配。
- 每个阶段开场叙述长度为 80～150 字符，全部插画引用有效。
- 运行文件没有远程资源 URL、ES Module、fetch、XHR 或远程样式导入。
- 242 次完整通关，包括各类兴趣投入、高压、低学习投入和混合选择。
- 全部数值始终在 0～100；每个阶段都能推进，无提前锁死。
- 30 次低学习投入自然进入完整职教线并完成三个变体阶段。
- 反复存读档后，同种子同选择的完整日志与高考结果完全一致。
- 自动存档在介绍、决策、反馈、阶段总结等状态均可往返读取。
- 重复确认同一决策不重复生效。
- 赋分等级分界、六科满分结构、额外压力扣分与科目合计一致。
- 暂停考试、亲子疏离、五个普通成绩档、艺术、体育、竞赛、职教三种去向和两个叠加层均有确定性测试。
- 心理 <20 优先于录取，亲子疏离优先于艺术等特殊录取。
- 体育的体质条件、竞赛的阶段审核条件均不能绕过。
- 转科只替换一门，实际扣除新科能力 25、精力 20、心理 10，重复点击无效。
- 非法数值和损坏存档被拒绝。
- 存储被禁用时可继续推进游戏。
- 导入时成就与结局图鉴能够合并。

## 浏览器检查

在 Chrome 中进行了本地静态预览，检查了：

- 首页、称呼与种子表单、连续阶段推进和反馈页。
- 桌面左右栏布局、家庭档案栏显示与自动存档恢复。
- 数字键选择与 Enter 确认。
- 手动存档槽保存。
- 结局页成绩明细、隐藏值揭示、时间线展开与 SVG 图表。
- 390px 嵌入视口下的小屏布局、顶部可折叠档案栏与固定底部操作区。
- 小屏深色模式；实测内容宽度不超过视口，没有横向溢出。
- JSON 导出按钮实际生成下载文件。
- 该 JSON 可被导入入口读取并通过格式验证，进入覆盖确认页。

浏览器工具在最后一次导入确认操作时连接超时，未把该次 UI 点击列为已完成的端到端通过项；完整状态恢复、随机序列与图鉴合并已由自动测试覆盖。

## 检查边界

- 未在真实 iOS/Android 设备及每个品牌的文件管理器内嵌预览器中逐一测试。
- 浏览器视觉检查通过本地 HTTP 静态预览完成；file 协议兼容性通过普通脚本加载、相对路径、零本地数据请求、无模块依赖等结构检查确认，未声称执行过 Windows 资源管理器双击测试。
- 升学参数为游戏综合模拟；未声称是省份统计平均值或最新政策复刻。
- 自动模拟用于检验可达性、稳定性与数值范围，不构成所有可能选择序列的穷举证明。

运行检查不参与玩家游玩，也不要求玩家安装 Node.js。
